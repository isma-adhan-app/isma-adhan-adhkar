# اسمع أذان وأذكار

برنامج ويندوز مجاني لمواقيت الصلاة والأذان والأذكار الصوتية، مصمم خصيصًا
للمكفوفين ويعمل بالكامل بلوحة المفاتيح مع قارئ الشاشة.

## ما الذي يقدمه البرنامج؟

- **مواقيت صلاة دقيقة بدون إنترنت** بطريقة الهيئة المصرية العامة للمساحة،
  مع اختيار المدينة من الإعدادات (الافتراضي: القاهرة).
- **تشغيل الأذان** في كل وقت صلاة، مع مكتبة أصوات يمكنك إضافة ملفاتك
  الخاصة إليها (MP3 أو WAV). حتى تضيف صوت أذان، يشغّل البرنامج تنبيهًا
  صوتيًا وينطق اسم الصلاة.
- **تنبيه قبل الأذان** من ٥ إلى ٦٠ دقيقة (تختار المدة من الإعدادات).
- **تنبيه الإقامة** بعد الأذان بعدد دقائق تحدده أنت.
- **أذكار صوتية** تُشغَّل بترتيب عشوائي كل ١٠ أو ١٥ أو ٢٠ أو ٣٠ دقيقة،
  مع ساعات هدوء ليلية (من ١١ مساءً إلى ٥ صباحًا) يمكن إيقافها.
- **تذكير سورة الكهف** يوم الجمعة في الوقت الذي تختاره.
- **أيقونة بجانب الساعة** (منطقة الإشعارات) وخيار التشغيل مع بدء ويندوز.
- عرض **التاريخ الهجري** بجانب الميلادي.

## اختصارات لوحة المفاتيح

| الاختصار | الوظيفة |
| --- | --- |
| Ctrl+A | تشغيل الأذان الآن |
| Ctrl+S | إيقاف الصوت |
| Ctrl+D | تشغيل أو إيقاف الأذكار |
| Ctrl+N | نطق الصلاة القادمة والوقت المتبقي |
| Ctrl+M | إخفاء النافذة إلى منطقة الإشعارات |
| Ctrl+Q | خروج من البرنامج |
| F1 | عرض هذه الاختصارات داخل البرنامج |
| Tab | التنقل بين كل عناصر النافذة |

## أول تشغيل

1. شغّل البرنامج، وافتح تبويب «الإعدادات» وتأكد من المدينة.
2. افتح تبويب «الأصوات» واضغط «إضافة صوت أذان» لاختيار ملف أذان من جهازك،
   ثم حدّده في القائمة واضغط «تعيين المحدد كصوت الأذان».
3. أضف مقاطع أذكار قصيرة بنفس الطريقة في قسم «مكتبة مقاطع الأذكار».
4. اضبط مستوى الصوت والتنبيهات من «الإعدادات» ثم اضغط «حفظ الإعدادات».

تُحفظ الإعدادات والأصوات في مجلد البرنامج داخل AppData، فلا تضيع عند
إعادة التشغيل.
